## Instructions for Taking Screenshots
1. Run local preview: `npm run preview` (serves at `http://localhost:4173/`).
2. Set browser window to standard resolution (e.g. 1280×800 for desktop, 1440×900 for wide desktop, and 390×844 in DevTools Device Mode for mobile).
3. Ensure zoom is set to 100% and default system fonts render cleanly.
4. Save screenshots as PNGs in `docs/screenshots/` (e.g. `01-home.png` to `10-mobile.png`) for inclusion in the final audition package.
